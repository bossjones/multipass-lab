single agent in a single context. The evidence is committed: a `.team/` directory holding real agent

no build step, no framework. This repo has *no* frontend toolchain today (pure uv + OpenTofu + just),
and `docs/slides/` will be its first frontend surface. That's fine: zero-dependency means it adds no
toolchain.

**Outcome:** `docs/slides/index.html` — a ~26-slide deck that opens in a browser, is

### Act 2 — The tools

**5. cmux: every terminal surface is an addressable object** `[HIGH]`
cmux is a macOS Ghostty-based terminal (`brew tap manaflow-ai/cmux && brew install --cask cmux`,
validated against `0.64.17`) that exposes a CLI + unix socket at `~/.local/state/cmux/cmux.sock`.
The object hierarchy:
- **Window** → a top-level OS window
- **Workspace** → a sidebar entry ("tab") inside a window
- **Pane** → a split region within a workspace
- **Surface** → a tab within a pane (a terminal **or a browser**)
*Visual:* nested-box CSS diagram, Window ⊃ Workspace ⊃ Pane ⊃ Surface, each labeled. This is the
core mental model of the whole deck — spend the pixels.

**6. boss-cmux: the natural-language driver** `[HIGH]`
A skill that turns "open a browser surface next to the lead and point it at the Grafana URL" into the
right cmux verbs. Grouped verb table:
- **Inspect** — `cmux tree --all` · `list-pane-surfaces` · `identify --json`
- **Create** — `workspace create --layout <json>` · `new-window` · `new-split` · `new-surface --type terminal|browser`
- **Control** — `send` · `send-key` · `read-screen --scrollback` · `close-surface`
- **Topology** — `move-surface` · `split-off` · `focus-pane` · `rename-tab` · `set-status`
- **Events** — `cmux events --name notification.requested`

**7. boss-cmux-team: one team = one workspace = one feature** `[HIGH]`
> "A **lead** agent (left half of the window) drives its **workers** (a grid on the right). You drive
> only the lead."
`spawn_team.py` reads a config (`--config` → `./.cmux/team.json` → bundled example) declaring `cwd`,
`env_file`, `completion_sentinel`, and a `roles[]` array **whose first role is the lead**. Each role
carries a `name`, a `model`, a `launcher`, a `prompt`, and a `kickoff` template with `__FEATURE__` /
`__APP_PATH__` / `__SENTINEL__` substituted at spawn.
*Visual:* the pane layout — big lead pane on the left, a balanced grid of worker panes on the right,
each with an emoji + role name + a 🔵/🟢 status pill. **Build this in CSS.** It is the deck's hero image.

**8. The spawn, end to end** `[HIGH]`
Five steps, as a numbered flow:
1. `ensure_cmux_running()` — `cmux identify --json`, else `open -a cmux` and poll ~15s.
2. `find_or_create_window()` — reuse the open window. **The UUID is the only stable handle.**
3. `build_layout()` — lead left-half; workers arranged into a **balanced binary split tree** (any N).
4. **One** `cmux workspace create --window <UUID> --name <feature> --cwd <dir> --env-file .env
   --layout <json> --focus true --json` — this boots *every pane's agent at once*.
5. `os.execvp("claude", [... "/cmux-did-spawn .team/<feature>.spawn.json"])` — the spawner **becomes**
   the orchestrator, already oriented.
Callout: `--env-file .env` injects credentials into every surface so agents come up authenticated —
*"Assume the keys are already set up, and never read their values."*

### Act 3 — The protocol

**9. The completion contract** `[LOW]`
Claude Code has **no deterministic turn-stop hook** (codex, gemini, pi, amp, cursor and ~10 others do).
So the contract is a printed sentinel:
```
TASK-DONE: <role> | <one-line summary>
```
> "Always tell a worker the exact `TASK-DONE` line to print, so you can detect completion."

**10. The one-line rule** `[LOW]` — the single most load-bearing gotcha.
> **`cmux send` submits a separate prompt on _every newline_.** A multi-line string is not one prompt
> — it is N prompts. **If a task is too big for one line, it is too big for one task. Split it.**
Also: **`send` types; `send-key enter` submits.** They are two separate calls. Forget the second and
your worker sits there with a full prompt buffer and does nothing.

**11. Push, don't poll** `[HIGH]`
Subscribe **before** the first prompt, then block on the event — don't burn tokens re-reading screens.
```bash
cmux events --name notification.requested --no-heartbeat --no-ack > /tmp/team.ev &
until grep -q "\"workspace_id\":\"$WS\"" /tmp/team.ev; do sleep 1; done
cmux read-screen --surface "$SURF" --lines 40
```
Callout: match on **`workspace_id`** — `surface_id` is usually `null`.

**12. The board is the state** `[HIGH]`
Every team writes `.team/<feature>.board.md`: an agent table (emoji · role · state · last log) plus an
explicit **FSM**. Workers keep their cmux tab pill current so the human can read the whole team's state
at a glance without opening a single pane:
```bash
cmux rename-tab --surface <UUID> "🔵 core 3/7 [███░░░] · rendering cloud-init"
```
🔵 working · 🟢 done · 🔴 error · ⚪ queued.

### Act 5 — Case study B: `docs-fleet`

**18. Ten agents, four shared files** `[HIGH]` — the collision problem, and the answer.
Five researchers can't collide (disjoint files). But `CLAUDE.md`, `README.md`, `docs/README.md` are
**shared**. The fix is not locking — it's **phase-locking + one owner per file**:

### Act 6 — Case study C: subagent fan-out (no cmux)

**20. `triage-logs`: keep the logs out of your context** `[HIGH]`
Not every fleet needs a terminal. When a cluster breaks, `/triage-logs` fans out **haiku**
`log-researcher` subagents — **one per suspect VM role** — that read the journals in parallel. The
verbose output stays *in their* contexts. Only distilled, **cited** findings come back. The main
**opus** agent then verifies those citations before touching anything.
Standing rules from the skill: *Partition up front · Summaries, never dumps · Verify before you fix ·
Reuse the tested engine (`uv run tools/system_debug.py` — never hand-rolled `ssh`/`journalctl`).*
*Visual:* fan-out where the thick "raw journal" arrows terminate INSIDE the researchers and only thin
"cited finding" arrows return. That asymmetry is the whole idea.

**21. Model tiering** `[HIGH]`
| Tier | Model | Job |
| --- | --- | --- |
| Orchestrator | `opus` (`cc: opus[1m]`) | Plan, dispatch, verify citations, own the FSM |
| Builder | `opus` / `codex gpt-5.5` | Write code, own one file set |
| Researcher | `haiku` | Read a lot, return a little |
| Reviewer | `opus`, read-only | Adversarial pass |
The economics: put the cheap model where the *tokens* are, and the expensive model where the
*judgment* is.

### Act 7 — Lessons

**22. What broke** `[HIGH]` — the honest slide.
- **Positional refs renumber.** `surface:3` is not a name; it shifts as surfaces open and close.
  Anchor to a **stable window UUID**.
- **`send` without `send-key`** = a worker sitting on a full prompt buffer, doing nothing, forever.
- **A multi-line prompt is N prompts.** Slide 10's rule, learned the hard way.
- **Fork agents overreach.** A fork inherits the *whole* plan and races on shared files. For isolated
  fan-out, use a general-purpose agent with a scoped brief — that's what Phase A of docs-fleet does.

**23. What the agents couldn't fix** `[LOW]` — the honest slide's honest slide.
The k0s lead hit a `multipassd` socket outage, correctly diagnosed it, and correctly **stopped**:
> "I cannot fix it — `sudo` requires a password (no askpass, no TTY). **Needs the HUMAN.**"
It killed the stuck `tofu apply` (pids 41790 / 41797 / 41933), routed clean-slate recovery to `ops`,
and escalated. Knowing the edge of your authority *is* the feature.

**24. What the fleet taught the repo** `[HIGH]`
Every failure the fleet hit became a permanent guardrail:
- **The silent wait-loop.** A VM stuck `cloud-init: running` for minutes with no failed unit isn't
  slow — an early install lost the **DNS warm-up race** (`curl: (6) Could not resolve host`), failed
  without aborting (`runcmd` is `/bin/sh`, no `set -e`), and a later `until …; do sleep 5; done` now
  loops forever, silently. → a resolver-ready gate + retry, now the standard cloud-init pattern.
- **Stale `.cross-cluster.auto.tfvars.json`.** Gitignored, auto-loaded by `tofu test`, and it silently
  flips the hermetic "off by default" assertions — *the hermetic suite was not actually hermetic.*
  → `just unwire`, and file-level `variables {}` blocks in every `.tftest.hcl`.
Both are now in `CLAUDE.md`, and the second became the `triage-patterns` skill.

### Act 8 — Close

**25. The rules that generalize** `[LOW]`
Six lines, big type. The whole deck compressed:
1. **Partition up front.** Disjoint files, or one owner per file. Never both agents in one file.
2. **Phase-lock the shared surfaces.** Fan out on research; serialize on authorship.
3. **Summaries, never dumps.** Keep the raw bytes in the cheap agent's context.
4. **A sentinel beats a poll.** `TASK-DONE:` — and subscribe before you prompt.
5. **Verify before you fix.** Cited evidence, or it didn't happen.
6. **Live patches don't count.** Backport it and rebuild from source, or it isn't real.
